# Карусели THE MHS

Рубрика в ленте параллельно рилсам. Формат — 1080×1350 (4:5), ник `@mhs.saas`, три цвета:
белый, чёрный, синий. Каждая карусель заканчивается лид-магнитом:
бесплатный AI-аудит бизнеса.

## Четыре шага

```
1. темы        carousel-topics      → carousel-topics-100.json     (100 тем, status: new)
2. утверждение пользователь          → status: approved / rejected
3. структура   carousel-structure    → carousel-decks/deck-XXX.json (слайды + caption)
   └ финал     carousel-cta          → блок cta внутри deck
4. рендер      npm run carousel      → output/carousel-cards/deck-XXX/slide-01.png …
```

Шаг 2 не пропускается. Пока темы не размечены — структуру не пишем.

## Команды

```bash
npm run carousel                  # отрисовать все утверждённые колоды
npm run carousel -- --only=7      # одну колоду
npm run carousel -- --theme=flood # прогнать колоду в другом дизайне
npm run carousel -- --scale=2     # 2160×2700, если нужен запас на кроп
npm run carousel:themes           # 5 вариантов дизайна одной колоды рядом
```

## Шесть дизайнов

| Ключ | Как выглядит | Под какие темы |
| --- | --- | --- |
| `grid` | Клетчатый лист, тяжёлый капс, инверсные плашки, слайд-цитата | основной, подходит всем |
| `invert` | Чёрная обложка, белые слайды тела, синий акцент | `list`, `people` |
| `flood` | Сплошной синий, белая типографика | `contra`, `future` |
| `blueprint` | Белый фон, синяя сетка, чертёжные подписи | `money`, `case` |
| `marker` | Белый фон, чёрный текст, синие плашки-выделения | `list`, `mistake` |
| `terminal` | Чёрный фон, моноширинные подписи, синий курсор | `prompt`, `system` |

Дизайн задаётся полем `theme` в колоде. Ключ `--theme` перебивает его на один прогон.

## Правила, которые нарушать нельзя

- **Последний слайд — всегда CTA** с лид-магнитом. Колода без него не рендерится.
- **Тело слайда — список из 4 пунктов**, каждый в одну строку до 46 знаков.
  Рендер сам подберёт кегль, но пункт длиннее строки завалит прогон.
- **Слайд-цитата** — один-два за карусель, на разрыв ритма.
- **3–11 слайдов.** Три — полноценный формат: обложка, одна плотная мысль, CTA.
  Больше одиннадцати не долистывают.
- **Число слайдов определяет агент**, а не человек и не поле `estimate`.
- **Лимиты знаков** из `carousel-structure.md` — это габариты вёрстки.
  Не влезло — рендер падает с ненулевым кодом.
- Safe zone: значимое — внутри полей 96 px по бокам, 120 сверху, 150 снизу.
  Низ съедает панель лайков и первая строка подписи.

## Содержание: три правила

- **Шире аудитория — выше охват.** Убери из темы отрасль: работает? Значит широкая.
- **Обложка бьёт в боль**, а не обещает пользу. Триггер в первую секунду.
- **Факты вместо воды.** Слайд без применимого факта вырезается.

## Агенты

- `carousel-topics` — 100 тем под четыре действия: прочитать, сохранить, прокомментировать, репостнуть.
- `carousel-structure` — сам считает несущие единицы темы и определяет число слайдов.
- `carousel-cta` — финальный слайд: карта автоматизации вместо слова «аудит».
