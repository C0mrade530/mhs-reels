# Аудио для рилсов

Положите сюда файлы треков (mp3 / m4a / wav). Генератор раскладывает их
по карточкам циклично: карточка 1 → трек 1, карточка 2 → трек 2 и так далее.

`tracks.json` задаёт для каждого файла точку входа и длительность нарезки:

    { "file": "montagem-rugada.mp3", "label": "MONTAGEM RUGADA", "start": 32, "duration": 9 }

- `start`    — с какой секунды трека резать (ставьте на дроп, а не на вступление);
- `duration` — длина ролика, допустимо 7–10 секунд;
- `label`    — как трек называется в отчёте.

Файлы, которых нет в `tracks.json`, берутся с начала и на 8 секунд.
Пока папка пуста, ролики собираются с тишиной — видео валидное, звук добавится
при следующем прогоне `npm run reels`.

## Права на музыку

Instagram сверяет звуковую дорожку с Rights Manager. Трек, вшитый в файл
без лицензии, приводит к заглушению звука, ограничению охвата или снятию ролика.
Кладите сюда только то, на что у вас есть права: собственную музыку,
royalty-free фонк (Uppbeat, Artlist, Epidemic Sound, Pixabay) или треки
с прямым разрешением автора.
