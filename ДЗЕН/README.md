Агент обязан открывать `ПРАВИЛА-ДЗЕНА.md` перед любой работой над текстом для Дзена
и проходить чек-лист до того, как отдать материал. Правила первичны: если приём
из `КАК-ПИСАТЬ-СТАТЬИ.md` конфликтует с запретом — побеждает запрет.

Данные собраны 28 августа 2026. Официальные страницы `dzen.ru` из окружения агента
недоступны по сети, поэтому формулировки справки пересказаны по вторичным источникам;
пункты с пометкой `[не сверено]` нужно сверить глазами по ссылкам в конце файла правил.
